# E9: 修复 pi-scheduler TUI 显示不稳定 + 强化持久化

> 创建日期：2026-06-02 | 状态：doing
> 关联路线图：pi-extensions-bugs

## 一、背景与目标

两个问题需要修复：

1. **TUI 显示不稳定**：`fire()` 用 `display: true` 发消息到上方内容区，渲染不稳定。底部状态栏 `⏱ N` 是稳定的。
2. **定时任务不持久化**：timer 是内存中的 setTimeout，会话关闭后全部丢失。

## 二、方案

### S1: 去掉内容区渲染

- `fire()` 改 `display: false` — 消息不在内容区显示，只触发 turn 让 AI 处理提示内容
- 底部状态栏 `⏱ N` 已经稳定，无需改动
- `/tasks` 面板已有 `tasks-panel.ts`，功能完整，无需重做

### S2: 跨会话持久化

- 新增 `scheduler-store.ts` — 读写 `~/.pi/agent/scheduler-state.json`
- `create/cancel/fire` 时写入文件
- `session_start` 时从文件恢复未过期的 timer
- 定期清理已完成的 timer（避免文件膨胀）

## 三、影响范围

| 文件 | 改动 |
|------|------|
| `timer-engine.ts` | `fire()` 改 `display: false`；新增 store 写入 |
| `scheduler-store.ts`（新） | 文件持久化：read/write/clean |
| `index.ts` | session_start 从文件恢复 |
| `tests/*` | 新增 + 更新 |

## 四、不变量

- 底部状态栏 `⏱ N` 显示不变
- `/tasks` 交互面板不变
- 同会话内的 restore 逻辑不变
- `/loop`、`/remind`、`/tasks` 命令行为不变
- `schedule` 工具行为不变
